I applied for LinkedIn API access, waited two weeks, and got rejected for a
reason I hadn't considered. Posting about it here, which I appreciate is a
little on the nose.

The rejection said nothing about my code, my privacy policy, or what the app
does. It came down to one line:

"Identity vetting failed. We were unable to verify that your organization is
a legally registered, active entity."

The fix they suggested was a link to an organisational website. I'd given
them the project's GitHub Pages docs site. Not accepted.

I ran those two things together for weeks. The requirement is proof that a
legally registered entity exists. The website is just the evidence they ask
for by default, because it's the fastest thing for a reviewer to check. A
docs site proves a project exists. It proves nothing about registration.

And I read the question as being about size, so I answered no — a repo and
one user. It isn't about size. I've had an active sole-trader ABN, on a
public government register, since months before I created the app. I never
gave it to them.

The rejection also isn't final. There's a vetting appeal form, and it asks
for exactly that: a registration someone can look up. Mine's in flight.

The estimate I got wrong is the transferable part. I scoped four social
integrations as engineering work. The code was hours each. Platform access
was weeks, and two of the four failed on criteria no amount of code could
satisfy — one on price, one on paperwork I had sitting in a drawer.

If you're planning this for a side project: budget the approvals, not the
integrations.
